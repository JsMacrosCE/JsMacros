# JsMacrosCE

This mod allows for the development of scripts to interact with the chat, and other parts of the world, using a
scripting language.  
More information and documentation of all features and modules can be found on the
website: <https://jsmacrosce.com>

## Extensions

Extensions add scripting languages or give scripts new libraries to call.
The [extension guide](https://jsmacrosce.com/guide/advanced/extensions) shows
how to install an extension and build your own from the
[Example Extension](https://github.com/JsMacrosCE/JsMacrosCE-Example-Extension).

## Nightly Builds


Development builds are automatically published for testing on each commit to the `main` branch. These builds are accessible via the [GitHub Releases page](https://github.com/JsMacrosCE/JsMacros/releases).
