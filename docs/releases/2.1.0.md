## Highlights

- Supports Minecraft **1.21.5, 1.21.8, 1.21.10, 1.21.11, 26.1.2, 26.2, and 26.3** on Fabric and NeoForge. Choose the JAR for your Minecraft version and loader.
- The [documentation site](https://jsmacrosce.com/) now has a scripting guide and a separate API reference for each Minecraft version. The GitHub devkit ZIP includes the offline site, TypeScript declarations, and Python stubs.
- Scripts can use type names like `EntityHelpers.Horse` without hard-coding Java package names. `JsMacros.stopScript()` stops the current run and removes its event listeners.
- Rendering additions include `Draw2D.clear()`, visibility and element controls for `Draw3D`, surface lighting controls, and the `Color` library for packed colors.

## Upgrading

- JavaScript is built in. For Python, replace the old GraalPython extension with `jsmacrosce-ext-graalpy-2.1.0.jar` from GitHub Releases. Put it in `config/jsMacros/Extensions/`, not in `mods/`. The same extension JAR works across all supported Minecraft versions and loaders.
- Use `com.jsmacrosce` instead of `xyz.wagyourtail` for direct JsMacros Java class lookups. Prefer the script type namespaces where they provide the type you need.
- Prefer Mojang packet names in new scripts. Packet filters still accept legacy names, and send/receive event `type` values still use the legacy names where available.
- On a fresh config, the default `ProfileLoad` trigger for `index.js` starts disabled. Enable it in the Events tab if you want that script to run on profile load.
